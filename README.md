# MY케어 (MY Care)

1인 뷰티샵 원장님을 위한 AI 기반 고객 기록 관리 및 시술 전 브리핑 서비스입니다.

⬇️프로그램 실행 방법⬇️

1. `결과` 폴더에서 `MY케어_제출용.ZIP` 파일을 다운로드한 후 압축을 해제합니다.
2. Python이 설치된 Windows 환경에서 `0-install.bat`을 실행하여 필요한 라이브러리를 설치합니다.
3. 설치가 완료되면 `1-run-MYcare.bat`을 실행합니다.
4. 웹사이트가 실행되면 고객 등록, 예약 조회, 시술 메모 및 AI 브리핑 기능을 확인할 수 있습니다.

※ Gemini AI 분석은 프로그램 내 설정에서 개인 API 키를 등록해야 사용할 수 있습니다.

※ Google Calendar 연동은 별도의 Google OAuth 인증 파일(credentials.json)이 필요합니다. 인증 파일이 없어도 고객 등록 및 메모 관리 등 기본 기능은 이용할 수 있습니다.
